# 🏦 BankAssist

BankAssist is a simple banking support assistant that helps users with common banking-related questions.

## ✨ Features

- Ask banking-related questions
- Get AI-generated responses
- Simple and user-friendly chat interface
- Clear chat option
- Banking support for common issues such as:
  - ATM PIN reset
  - Lost cards
  - Unauthorized transactions
  - General banking queries

## 🛠️ Technologies Used

- Java
- Spring Boot
- HTML
- CSS
- JavaScript
- Ollama

## 🚀 How to Run

1. Clone this repository.
2. Open the project in your IDE.
3. Make sure Ollama is installed and running.
4. Start the Spring Boot application.
5. Open the application in your browser.

## 💬 Example

User:

> How can I reset my ATM PIN?

BankAssist provides general steps to help the user reset their PIN safely.

## 🔐 Security

BankAssist does not ask users to provide sensitive information such as PINs, passwords, or login credentials.
